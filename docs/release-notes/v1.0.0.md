# BrewLite v1.0.0 — Release notes

Ngày phát hành: 23/11/2026
Tag: `v1.0.0`

Bản đầu tiên bàn giao cho Assignment 2 (Requirements to Deployment): luồng đặt cà phê
không dùng tiền mặt từ xem menu đến thanh toán và theo dõi đơn.

## Tính năng
- **Khách hàng:** menu (tìm kiếm, lọc, sắp xếp, phân trang), chi tiết món (size, topping, đường, đá), giỏ hàng (gộp món trùng, sửa/xóa, tự tính tiền), đăng ký/đăng nhập JWT, tạo đơn, thanh toán Ví/Thẻ mô phỏng, xác nhận đơn và lịch sử đơn.
- **Nghiệp vụ backend (Task 10):** máy trạng thái đơn hàng, thanh toán idempotent (`Idempotency-Key`), kiểm soát tồn kho khi đặt đồng thời, khuyến mãi và điểm thưởng.
- **Quầy/Quản trị:** màn hình Barista (KDS), quản lý sản phẩm, kho và đơn hàng, doanh thu.
- **PWA / mobile-first** cho frontend Next.js.

## Hạ tầng và chất lượng
- Docker Compose chạy db + backend + frontend ở local.
- CI: lint/test/build khi mở pull request; workflow triển khai lên Render qua GitHub Actions; smoke test `tests/smoke-test.sh`.
- **E2E Playwright** (`e2e/`) cho luồng menu → giỏ → đăng nhập → thanh toán → xác nhận và thanh toán lỗi; workflow `e2e.yml`.
- **Request id:** mọi response có header `X-Request-Id`; log API ghi `[requestId] METHOD path status duration`.
- Quy ước commit (commitlint, Conventional Commits) và PR template có checklist Definition of Done.

## Thay đổi đáng chú ý
- Bổ sung cột `stock` cho sản phẩm (migration `20261115000000_add_product_stock`).
- Thêm header `X-Request-Id` (CORS đã expose header này).

## Hạn chế đã biết
- Khi chạy `docker compose up` với database mới, backend có thể dừng với lỗi Prisma P3005, vì compose nạp `brewlite_database.sql` (đã có sẵn bảng) rồi Dockerfile lại chạy `prisma migrate deploy`. Workaround dùng cho e2e: `e2e/docker-compose.e2e.yml`.
- Cổng thanh toán là mô phỏng (mock), chưa tích hợp cổng thật.
- Backend đã có `POST /orders/:id/cancel`, nhưng nút "Xác nhận hủy" trên giao diện chưa được nối với API này (đang bị vô hiệu hóa).
